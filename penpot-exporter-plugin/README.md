# Penpot Exporter Plugin

Run `npm install` and `npm run build`, serve `public`, then install `public/manifest.json` through Penpot Plugin Manager. The plugin exports Penpot structure, Component and Variant metadata, responsive constraints, and deduplicated PNGs only for complex visual layers that need raster fallback.

See the repository [guide](../docs/GUIDE.md) for the complete workflow.
